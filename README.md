# 오브릭 ORBRIC

**오브릭(ORBRIC, [orbric.xyz](https://orbric.xyz/))** 은 축구, 야구, 농구 경기 기록을 조건별로 걸러 보는 한국어 스포츠 데이터 분석 서비스입니다.

경기 전에 "이 팀 원정 밤 경기 성적은?", "이 선발투수가 나온 날은?" 같은 걸 여러 기록 사이트를 오가지 않고 바로 볼 수 있게 만들었습니다. 홈/원정, 상대 팀, 선발투수, 낮/밤, 요일 같은 조건을 엑셀 필터처럼 섞어 쓰면 그 조건에서 실제로 나온 결과가 표로 걸러집니다. 경기마다 두 팀의 상대전적, 최근 흐름, 순위 지표를 모은 분석 페이지도 있습니다.

ORBRIC is a Korean sports data service for filtering soccer, baseball and basketball match records by condition, with match analysis built on 10+ years of game records.

- 야구 / Baseball: MLB, KBO, NPB, CPBL
- 농구 / Basketball: NBA, KBL, WKBL
- 축구 / Soccer: 유럽 주요 리그를 포함한 여러 나라 리그 / leagues worldwide

바로가기: [오브릭 홈](https://orbric.xyz/) · [소개](https://orbric.xyz/about) · [방법론](https://orbric.xyz/methodology)

모든 내용은 과거 기록을 요약한 참고 자료이며 경기 결과를 보장하지 않습니다.

## 이름에 대하여

오브릭(ORBRIC)은 스포츠 데이터 서비스이고, 이름이 같은 블록 부품 쇼핑몰 등 다른 업종의 '오브릭'과는 관계가 없습니다. 공식 주소는 orbric.xyz 하나입니다.
