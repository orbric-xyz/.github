# ORBRIC (오브릭) — Sports data analysis · 스포츠 데이터 분석

**오브릭(ORBRIC, [orbric.xyz](https://orbric.xyz/))** 은 축구·야구·농구 경기 데이터와 초기 배당 기록을 근거로
경기 분석과 시그널을 제공하는 **한국어 스포츠 데이터 분석 서비스**입니다.

ORBRIC is a Korean sports data analysis service. It turns match records and opening odds into
signals for football (worldwide leagues), baseball (MLB · KBO · NPB · CPBL) and basketball (NBA · KBL · WKBL).

## 무엇을 제공하나 / What it provides

| 콘텐츠 | 설명 |
|---|---|
| 오즈 시그널 (Odds Signal) | 북메이커가 처음 내놓은 초기 배당(오프닝 배당)과 정확히 같은 배당이 매겨졌던 과거 경기의 실제 결과를 집계해 확률로 정리한 축구 분석 |
| 매치 시그널 (Match Signal) | 최근 흐름·상대전적·순위 등 항목별 근거를 모아 어느 팀이 유리한지 방향을 보여 주는 분석 (야구는 선발투수·팀 타격 항목 추가) |
| 첫볼넷·첫삼진·첫홈런 시그널 | 그 경기에서 볼넷·삼진·홈런이 어느 쪽에서 먼저 나올 흐름인지 방향을 보여 주는 야구 분석(선발투수 관련 기록 + 두 팀 타자들의 최근 흐름 비교) |
| 경기 분석 · 데이터 필터링 · 라이벌 더비 | 경기별 분석 페이지, 조건별 야구 통계, 라이벌 맞대결 모아보기 |

모든 시그널과 분석은 과거 데이터를 요약한 참고 자료이며 앞으로의 경기 결과를 보장하지 않습니다.
All signals are summaries of historical data and do not guarantee future results.
